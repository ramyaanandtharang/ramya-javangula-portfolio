# Ramya Javangula — Portfolio

Personal portfolio for Ramya Javangula, Senior Data Analyst (Operations Analytics). A single-page site covering featured work, the AI approach, experience, skills, certifications and contact details.

## Technologies
- Plain HTML and CSS, with a small inline script for scroll fade-ins. No build step.
- Google Fonts (DM Sans, Instrument Serif)
- Netlify hosting, with Netlify Image CDN serving an optimized portrait

## Run locally
```
netlify dev
```
Or open `public/index.html` directly in a browser. The portrait loads through `/.netlify/images`, so it only shows when the site runs under `netlify dev` or is deployed.

## Editing
All content is in `public/index.html`. To change the portrait, replace `public/photo.jpeg`.
